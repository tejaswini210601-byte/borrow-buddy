# Borrow Buddy

**Borrow more. Buy less. Share better.**

Borrow Buddy is a community borrowing and lending platform: list things you rarely use, discover items near you, request to borrow them, and manage returns.

> 🚧 Work in progress. Setup instructions will be added as the project is built.

## Planned tech stack
- Next.js (App Router) + TypeScript
- Tailwind CSS + shadcn/ui
- Supabase (PostgreSQL database, Auth, Storage)
- Deployed on Vercel
